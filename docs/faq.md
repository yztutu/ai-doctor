# 常见问题

**Q：支持哪些接口？**
A：一切 OpenAI 兼容格式：官方 API、Azure、各家中转/聚合站、Ollama 与 LM Studio 的本地网关。

**Q：key 会被保存或上传吗？**
A：不会。只从 `--key` 或环境变量读取，进程结束即消失；脚本零依赖、源码可审计。

**Q：流式测出来很慢说明什么？**
A：首字（TTFT）慢多半是排队/冷启动/中转层数多；每秒块数低是生成端慢或被限速。换个时段再测一次对比。

**Q：JSON 模式"返回非 JSON"？**
A：有些中转站声称支持 `response_format` 实际忽略参数，这项就是用来抓这个的。

**Q：长上下文失败就是模型假？**
A：不一定，也可能只是该渠道的上限小；但回执 token 数和宣称严重不符时值得警惕。
